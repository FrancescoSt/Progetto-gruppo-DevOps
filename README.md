# Progetto-gruppo-DevOps
Progetto gruppo DevOps. Gruppo formato da: Dario, Francesco Stoppa, Giacomo e Giovanni

Comandi git veloci per capire come funziona
1)git switch -c nome del branch 
utilizizamo questo perche non possiamo subito modificare il file dal main
2)git add nome file modificato
con questo diciamo quale file abbiamo modificato
3)git commit -m "descrizione del commit"
utilizizamo questo git per fare capire agli altri cosa abbiamo fatto
4)git push origin nome branch
cosi facendo arrivas la richiesta e bisogna farla accettare
5) git branch -d nome branch
per cancellare un branch che non ci serve piu
